# 사운드 폴더

```
assets/sound/
├─ bgm/   배경음악 (기본 1곡 + 오리진별 곡)
└─ sfx/   효과음 (짧은 파일)
```

어떤 소리를 어디에 쓸지는 **`js/sound-config.js`** 에서 정한다. 파일을 넣은 뒤 그 파일 경로(또는 유튜브 링크)를 적으면 된다.

## 배경음악 (`bgm/`)

| 설정 키 | 재생되는 때 |
| --- | --- |
| `main` | 기본. 계속 반복 재생된다 |
| `origins.just` ~ `origins.mary` | 그 오리진의 프로필을 열었을 때. 닫으면 기본 배경음악으로 돌아간다 |

- 곡이 바뀔 때는 `fadeMs`(기본 1.4초) 동안 페이드 아웃 → 페이드 인 된다.
- 기본 배경음악은 멈췄던 지점부터 다시 이어서 재생된다.
- 곡을 비워 둔 오리진은 기본 배경음악이 그대로 이어진다.
- 브라우저 정책상 소리는 방문자가 화면을 한 번 클릭(또는 키 입력)한 뒤부터 나온다. 접속 화면의 SKIP / Enter도 여기에 해당한다.
- 오른쪽 위 `SOUND ON/OFF` 버튼으로 끌 수 있고, 방문자 브라우저에 기억된다.

### 유튜브 링크 vs mp3

| | 유튜브 링크 | mp3 파일 |
| --- | --- | --- |
| 준비 | 링크만 붙이면 됨 | 파일을 구해서 `bgm/`에 업로드 |
| 페이드 인/아웃 | 됨 | 됨 (아이폰 사파리는 볼륨 조절이 막혀 있어 즉시 전환) |
| 안정성 | 영상 주인이 **퍼가기를 막았거나**, 영상이 삭제·비공개되면 재생 안 됨. 광고가 끼어들 수 있음 | 항상 재생됨 |
| 로딩 | 유튜브 플레이어를 불러오느라 첫 재생이 1~2초 늦음 | 빠름 |

먼저 유튜브 링크로 넣어 보고, 재생이 안 되는 곡만 mp3로 바꾸는 방식을 추천한다.

## 효과음 (`sfx/`)

아래 이름으로 파일을 넣으면 바로 적용된다. 없는 파일은 그냥 조용히 넘어간다.

| 파일 | 재생되는 때 |
| --- | --- |
| `click.mp3` | 탭 전환, 연표 마커, 확대/축소, 필터 같은 일반 버튼 |
| `hover.mp3` | 인덱스 메뉴나 행성 마커에 커서를 올릴 때 (아주 짧고 작은 소리 추천) |
| `open.mp3` | 창·팝업이 켜질 때 (전원이 켜지는 소리) |
| `close.mp3` | 창·팝업이 꺼질 때 |
| `reveal.mp3` | 스포일러 열람, 초월자 기록 전환 (글리치·해독음) |
| `type.mp3` | 접속 화면에서 ID·비밀번호가 입력될 때 |
| `granted.mp3` | 접속 화면 ACCESS GRANTED |

효과음은 0.1~0.5초 정도의 짧은 파일이 좋다. 유튜브 링크는 효과음에 쓸 수 없다.
